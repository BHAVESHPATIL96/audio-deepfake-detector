# 🎙️ Advanced Audio Deepfake Detector

A Streamlit-based application to detect real vs fake audio using MFCC features and a pre-trained machine learning model.

## 🚀 How to Run

1. Clone the repo:
```bash
git clone https://github.com/YOUR_USERNAME/audio-deepfake-detector.git
cd audio-deepfake-detector
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Run the app:
```bash
streamlit run deepfake.py
```

## 📌 Features
- Upload `.wav`, `.mp3`, or `.m4a` files
- MFCC feature extraction
- Pre-trained ML model for prediction
- Confidence score display
- Waveform visualization
